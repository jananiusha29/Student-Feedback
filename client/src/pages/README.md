# 🎓 Student Feedback System

A Full Stack Student Feedback System built using React, Node.js, Express, HTML, CSS and JavaScript.

## Features

- Add Feedback
- Edit Feedback
- Delete Feedback
- Search Feedback
- Rating System
- Dashboard
- Dark Mode
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express
- JSON File
